# Festivite

Formulário web para criação de convites digitais para eventos. O projeto faz parte dos estudos de HTML e CSS da Rocketseat.

## Acesse o projeto

[Abrir o Festivite](https://carolrodrigues14.github.io/rocketseat-fullstack/HTML-CSS/05-FormularioConvite/)

## Preview

A página apresenta um formulário dividido em etapas:

- informações do evento;
- tipo e local do evento;
- descrição;
- personalização de cores e tema;
- estilo claro ou escuro;
- seleção de foto de capa;
- dados para contato;
- aceite de termos e preferências de comunicação.

## Tecnologias

- HTML5
- CSS3

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.

Também é possível iniciar um servidor local na pasta do projeto:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000` no navegador.

## Status

Interface do formulário implementada com HTML e CSS. O projeto ainda não possui uma camada de JavaScript ou backend para processar e gerar os convites.
